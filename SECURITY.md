# Security

Better Task Manager is an administrator-focused Windows utility. It intentionally requests elevated privileges because several features need them.

## Elevated Actions

The app may:

- Read process metadata.
- Force-kill selected processes.
- Trim process working sets.
- Request Windows memory cleanup operations.
- Add or remove Windows Firewall rules for selected executable paths.

## Reporting Issues

Do not include private IP addresses, usernames, full file paths, process lists, or connection history in public issues unless you have reviewed and sanitized them.

For sensitive reports, create a private advisory or contact the maintainer privately once the project has a public maintainer channel.
